# 数据处理智能体 — 界面设计方案

## 一、设计原则

| 原则 | 说明 |
|------|------|
| **专业密度** | 对标广联达、用友BIP风格 — 数据密集、功能可见、操作直达 |
| **线性推进** | 数据处理全流程采用步骤条（Steps）引导，每步完成→下一步解锁 |
| **三系统一体** | 单页面内无缝切换数据处理/估值(DRAP)/合规(法规智能体) |
| **实时反馈** | 操作结果即时展示，质量报告、清洗前后对比可视化 |
| **响应式** | 适配1920px桌面为主，兼顾1366px笔记本 |

## 二、页面架构（6大页面）

```
┌─────────────────────────────────────────────┐
│  顶部导航: Logo | 仪表盘 | 数据管道 | 数据目录  │
│            | 质量监控 | 资产估值 | 合规中心      │
├─────────────────────────────────────────────┤
│                                             │
│   (活动页面内容区)                            │
│                                             │
├─────────────────────────────────────────────┤
│  底部状态栏: 系统状态 | Agent状态 | DRAP连接  │
│              | 法规库状态 | 最近操作           │
└─────────────────────────────────────────────┘
```

### P1. 仪表盘 (Dashboard)
- 系统健康概览（Agent状态、存储层统计）
- 数据资产全景（Bronze源/Silver表/Gold数据集数量）
- 最近数据处理活动列表
- DRAP 估值引擎连接状态
- 快速操作入口（接入数据/清洗数据/估值入表）

### P2. 数据管道 (Pipeline) — 核心页面
- **步骤条向导**: ①选择源→②探查→③清洗→④集成→⑤治理→⑥分析→⑦资产化
- 每步展示操作表单 + 结果预览
- 左侧: 步骤进度条
- 右侧: 当前步骤表单
- 底部: 操作日志

### P3. 数据目录 (Catalog)
- 三层视图切换: Bronze / Silver / Gold
- Bronze: 按数据源/日期浏览，显示行数/列数/大小
- Silver: 按主题域/表浏览，显示表结构
- Gold: 聚合数据集，支持预览前N行
- 搜索 + 筛选

### P4. 质量监控 (Quality)
- 数据质量仪表盘: 完整性/准确性/一致性/时效性/唯一性 雷达图
- 质量趋势折线图
- 问题列表（异常值/缺失/重复）
- 质量规则管理

### P5. 资产估值 (Valuation) — 对接DRAP
- 估值方法选择: BSC / ANP / 行业(金融/制造/互联网)
- 估值参数配置
- 估值结果展示（成本法/收益法/市场法对比）
- 审计底稿生成按钮
- 台账列表

### P6. 合规中心 (Compliance)
- 10阶段法规检查入口
- 合规检查结果展示
- 法规原文引用
- 法规更新日志
